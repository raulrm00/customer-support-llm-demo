# Backend - Customer Support Classifier API

FastAPI microservice that exposes a prediction API for customer support requests using a persisted scikit-learn pipeline.

## Key features
- Inference for a fixed set of support categories.
- Health endpoint for liveness checks.
- Pydantic validation for all API inputs and outputs.
- OpenAPI (Swagger) documentation auto-generated by FastAPI.

## Requirements
- Python 3.11+ (3.13+ tested)
- A trained model artifact at `ml/models/modelo_idf.joblib` and optional metadata at `ml/models/model_metadata.json`.

## Local development
1. Create and activate a virtual environment:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

2. Install dependencies:

```powershell
pip install -r backend/requirements.txt -r backend/requirements-dev.txt
```

3. Configure environment variables:
Copy `.env.example` to `.env` and adjust values (DB URL, model paths, JWT secret).

4. Run the app in development mode (hot reload):

```powershell
cd backend
uvicorn app.main:app --reload
```

Open the API docs at: http://localhost:8000/docs

## Docker
Build and run from the repository root:

```powershell
docker build -t customer-support-backend -f backend/Dockerfile .
docker run -p 8000:8000 --env-file .env customer-support-backend
```

## Testing & Quality checks
- Formatting: `black app`
- Linting: `ruff check app`
- Type checks (optional): `mypy app`
- Tests: `pytest` (run from `backend/`)

Notes for CI and local testing:
- Tests use FastAPI TestClient. To avoid requiring a Postgres instance during tests, set `DATABASE_URL` to a local SQLite URL (e.g. `sqlite:///./test.db`) in your test environment or CI job.
- Consider running tests inside a virtual environment with the dev requirements installed.

## API endpoints (short)
- GET /api/v1/health — minimal health response.
- POST /api/v1/predictions — classify a single support request. Request body: `{ "instruction": "text" }`.

## Practical recommendations
- Keep model artifacts and metadata tracked via DVC for large files.
- Do not commit `.env` or secrets to the repository.
- Add integration tests that run with a transient SQLite DB to validate request/response contracts.
